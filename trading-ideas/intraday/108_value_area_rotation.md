# 108 — Value Area Rotation

## Overview

Trade rotation between the value area low and value area high when the day is balanced. The setup is designed for range days where breakout systems are likely to underperform.

## Setup & Entry Rules

| Parameter | Value |
| --- | --- |
| Timeframe | 5-min chart |
| Markets | VN30F, liquid stocks |
| Reference | Intraday volume profile value area |

### Long Entry
1. Day forms a balanced profile after the first hour.
2. Price tests value area low and fails to break lower.
3. Delta/volume pressure weakens on the test.
4. Enter long on reclaim of value area low.
5. Stop below failed test low.

### Short Entry
1. Balanced profile is established.
2. Price tests value area high and fails to break higher.
3. Buying pressure weakens.
4. Enter short on rejection back into value.
5. Stop above failed test high.

## Exit Rules

- Primary target: point of control.
- Secondary target: opposite side of value area.
- Exit if price accepts outside value area for 2 candles.

## Filters

- Do not use on trend days with one-directional value migration.
- Best after first hour once value area is meaningful.
- Avoid if major news is pending.

## Risk Management

Risk 0.5%-0.75%. Stop must sit outside the failed value-area test.
