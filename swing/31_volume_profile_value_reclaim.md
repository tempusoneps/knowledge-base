# 31 — Volume Profile Value Reclaim

## Overview
Buy when price reclaims a multi-week high-volume value area after a shakeout below it.

## Setup & Entry Rules
- Build a 3-6 month volume profile.
- Identify high-volume value area.
- Price undercuts value, then reclaims it on daily close.
- Enter on reclaim or first retest that holds.
- Stop below reclaim low.

## Exit Rules
- Target value area high first.
- Second target: low-volume zone above value.
- Exit if price closes back below value area.

## Filters
- Stronger if value area aligns with 50-day or 200-day MA.
- Avoid if new catalyst invalidates prior value.
- Use liquid stocks with reliable volume data.

## Risk Management
Risk 0.5%-1%. Profile levels are zones; allow reasonable noise.
