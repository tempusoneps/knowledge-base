# 08 — Value-Momentum Rotation

## Overview
Rotate between value and momentum factors based on which factor has stronger recent performance.

## Setup & Entry Rules
- Build value and momentum factor baskets.
- Compare 3-month factor returns.
- Allocate more to outperforming factor while maintaining diversification.
- Rebalance monthly.

## Exit Rules
- Reduce factor when its 3-month relative trend breaks.
- Rebalance to neutral if both factors are weak.

## Filters
- Avoid excessive turnover with signal buffer.
- Sector-neutral variants reduce unintended bets.

## Risk Management
Volatility target each factor sleeve.
