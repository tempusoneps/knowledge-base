# 08 — Index Member vs Index Future Hedge

## Overview
Long a strong index component while shorting index futures to isolate stock-specific alpha.

## Setup & Entry Rules
- Stock shows strong relative strength and catalyst.
- Hedge with index future using beta estimate.
- Enter when stock breaks out while index is neutral or weak.
- Rebalance hedge if beta changes.

## Exit Rules
- Exit if stock loses breakout level.
- Cover hedge when stock-specific target is reached.

## Filters
- Best for high index-weight liquid stocks.
- Avoid earnings gaps unless intended.

## Risk Management
Track residual beta and basis risk. Futures hedge can underperform in sharp rotations.
